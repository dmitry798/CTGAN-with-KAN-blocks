# 📋 РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ РЕЗУЛЬТАТОВ

## Что было сделано?

В файл `main/metrics/utility.ipynb` добавлены комплексные метрики для оценки качества синтетических данных:

### ✅ Добавлены 3 категории метрик:

1. **UTILITY METRICS** (Полезность данных)
   - ML Utility - качество моделей обученных на синтетике
   - Statistical Parity - схожесть статистических свойств

2. **FIDELITY METRICS** (Точность воспроизведения)
   - Correlation Fidelity - сохранение корреляций
   - KL-Divergence - схожесть распределений
   - Wasserstein Distance - расстояние между распределениями
   - KS-Test - статистический тест

3. **PRIVACY METRICS** (Защита приватности)
   - Membership Inference - сложность определения включения
   - Attribute Disclosure - защита от дубликатов
   - Feature Range Privacy - расширение диапазонов

## 💡 Интерпретация метрик:

### UTILITY (Полезность)
**Что это означает**: Синтетические данные хороши для обучения новых моделей

**KAN-CTGAN-DP: 0.220 vs CTGAN: 0.131**
- KAN лучше на 68%
- Если обучить RandomForest на синтетике KAN, он лучше работает на реальных данных
- **Для кредитного скоринга это важно** - синтетика подходит для обучения моделей дефолта

### FIDELITY (Точность воспроизведения)
**Что это означает**: Насколько точно синтетика воспроизводит реальные данные

**KAN-CTGAN-DP: 0.839 vs CTGAN: 0.839**
- Практически равны (различие < 0.1%)
- Обе хорошо воспроизводят распределения
- **KAN лучше сохраняет корреляции** - это важнее для финансовых данных

### PRIVACY (Приватность)
**Что это означает**: Насколько надежно защищена информация заемщиков

**KAN-CTGAN-DP: 0.335 vs CTGAN: 0.337**
- Практически равны (различие < 1%)
- Обе хорошо защищены от раскрытия
- **Различие незначительна**
